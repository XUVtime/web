About this project

This is the CS2 Sniper Rifle Stats Database. It features all four sniper rifles in the game — AWP, G3SG1, SCAR-20 and SSG 08. Each page clearly displays core parameters including price, base damage, penetration multiplier, fire mode, fire rate, accessible sides and kill reward, helping you accurately compare the roles and performance of sniper rifles for easy weapon selection and stat reference.
